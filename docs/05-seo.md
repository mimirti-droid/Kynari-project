# 05 · SEO

## Bloque SEO por artículo

Cada artículo se genera con sus campos SEO estructurados, que viajan desde la generación hasta el CMS:

- Meta title
- Slug
- Meta description
- Extracto social (excerpt para redes)
- Tags

## Etiquetas

- Cada artículo lleva su etiqueta de categoría (`cinema`, `anime`, `games`, `culture`, `comic`).
- Los artículos Legacy llevan solo `legacy`.

## Pendiente para el lanzamiento

- Google Search Console (prioridad máxima).
- Bing Webmaster Tools.
- Analítica.
- Imagen de compartición social y cuentas sociales correctas en los ajustes de Ghost.
